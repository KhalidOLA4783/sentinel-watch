# 🛡️ SentinelWatch — Tour de Contrôle Sécurité, Audits Réels & App Mobile

> Système complet de détection d'intrusions (IA + Heuristiques), audit réel de sécurité de postes d'entreprise (EDR Posture Score), boîte à outils forensic VirusTotal et console mobile Android autonome.

---

### 🚀 Démarrage Ultra Rapide en 1 Clic (Sans Ligne de Commande)

Dans ce dossier (`C:\Users\Khaled\Videos\APK\`) :

1. **Allumer le Serveur SOC & Ouvrir la Console Web :**  
   👉 Double-cliquez sur **`LANCER_SERVEUR.bat`** *(Ouvre automatiquement `http://localhost:8000/dashboard`)*.
2. **Autoriser le Port Pare-feu pour le Smartphone :**  
   👉 Clic droit sur **`AUTORISER_PORT_FIREWALL.bat`** > *Exécuter en tant qu'administrateur*.
3. **Compiler le Nouvel APK Android (Avec Connexion) :**  
   👉 Double-cliquez sur **`COMPILER_NOUVEL_APK.bat`** *(Compile l'appli et génère `SentinelWatch.apk` avec écran de connexion, autorisations Wi-Fi et pilote autonome)*.
4. **Connecter l'Application Mobile au PC :**  
   👉 Connectez-vous avec `admin` / `Admin123!` (l'adresse IP Wi-Fi est pré-remplie automatiquement).
5. **Lancer le Scan de Sécurité Réel de votre PC :**  
   👉 Double-cliquez sur **`LANCER_AUDIT.bat`** *(Analyse Windows Defender, Pare-feu, RDP/NLA, fichiers suspects et calcule votre score sur 100)*.
6. **Scanner un Fichier Suspect sur VirusTotal :**  
   👉 Glissez-déposez n'importe quel fichier sur **`VERIFIER_FICHIER_VIRUSTOTAL.bat`**.
