Contrôles Rapides Système (Vérifications & Remédiations)

Commandes prêtes à copier pour Windows
1. Fichier HOSTS (Détournement DNS)
C:\Windows\System32\drivers\etc\hosts

Les malwares modifient souvent ce fichier pour rediriger Google/banques vers des faux sites ou bloquer l'accès aux serveurs de mise à jour des antivirus.

Get-Content C:\Windows\System32\drivers\etc\hosts
notepad C:\Windows\System32\drivers\etc\hosts
2. Intégrité Système (SFC / DISM)
Réparation Windows

Vérifie et restaure automatiquement les fichiers système et DLLs de Windows qui auraient été altérés ou injectés par un logiciel malveillant.

DISM.exe /Online /Cleanup-image /Restorehealth
sfc /scannow
3. Bureau à Distance (RDP 3389 & NLA)
Vecteur #1 Ransomware

Exige impérativement le chiffrement NLA (Network Level Authentication) ou désactive le port RDP pour stopper les attaques par force brute.

Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp' -Name 'UserAuthentication' -Value 1
Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name 'fDenyTSConnections' -Value 1
4. Historique PowerShell (ConsoleHost)
Détection Stagers

Conserve la trace de toutes les commandes tapées : utile pour repérer les scripts furtifs (IEX, DownloadString, Mimikatz, encodages base64).

notepad (Get-PSReadLineOption).HistorySavePath
Clear-History; Remove-Item (Get-PSReadLineOption).HistorySavePath -ErrorAction SilentlyContinue

Les 4 Outils Gratuits Recommandés (Triage & Nettoyage d'Urgence)

Sysinternals Autoruns Microsoft

Affiche la liste exhaustive des programmes démarrant automatiquement : clés de registre Run, tâches planifiées, services, drivers et extensions shell.

Usage : Détecter où un malware se cache pour persister au redémarrage.
Télécharger Autoruns
Process Explorer Microsoft

Le gestionnaire de tâches ultime. Intègre nativement VirusTotal pour vérifier en temps réel le hash de chaque processus en cours d'exécution.

Usage : Identifier les processus suspects et injectés en mémoire.
Télécharger ProcExp
Sysinternals TCPView Microsoft

Fournit une liste détaillée en temps réel de tous les points de terminaison TCP et UDP, avec résolution DNS et adresses distantes connectées.

Usage : Débusquer les spywares communicant vers un serveur C2 externe.
Télécharger TCPView
AdwCleaner / MBAM Gratuit

Utilitaire autonome portable (sans installation). Éradique rapidement les adwares, barres d'outils parasites et programmes potentiellement indésirables (PUPs).

Usage : Nettoyage et désinfection immédiate d'un poste utilisateur infecté.
