## 💼 1. POST LINKEDIN (Format Recommandé : Impact Technique & Recrutement)

> 💡 **Conseil visuel pour LinkedIn** : Accompagnez ce post d'une image ou vidéo courte (ex: capture d'écran du Dashboard SOC avec le graphique d'activité et une alerte rouge en cours, ou une photo montrant votre PC avec le Dashboard et votre smartphone avec l'application Flutter).

```text
🛡️ Comment détecter et bloquer une cyberattaque en temps réel entre un poste de travail, le Cloud et un smartphone ?

Pour répondre concrètement à cette problématique, j'ai conçu et déployé de bout en bout SentinelWatch : une solution légère de détection de menaces (SIEM / EDR) autonome et multi-organisations.

💡 La problématique :
Les TPE/PME et équipes réduites manquent souvent de visibilité sur l'état de sécurité de leur parc sans devoir déployer des usines à gaz complexes. 

🎯 Ce que fait SentinelWatch :
1️⃣ Côté Postes (Windows) : Un agent EDR silencieux tourne en tâche de fond (PowerShell natif, 0 dépendance), audite Windows Defender, le pare-feu et les ports ouverts, puis remonte la télémétrie chiffrée.
2️⃣ Côté Cerveau Cloud (FastAPI & IA) : Analyse spatiotemporelle instantanée (corrélation Haversine pour repérer les voyages impossibles, détection brute-force) couplée à un modèle de Machine Learning non-supervisé (Isolation Forest) pour déceler les comportements atypiques.
3️⃣ Côté Pilotage (Web & Mobile) : 
   - Une console SOC Web interactive (React / Tailwind) pour cartographier le trafic et trier les incidents.
   - Une application mobile d'astreinte native (Flutter) permettant à l'analyste de valider le bannissement d'une IP malveillante en 1 clic (riposte immédiate).

⚙️ Stack technique :
• Backend & IA : Python 3.11, FastAPI, SQLAlchemy, Scikit-learn (Isolation Forest)
• Déploiement Cloud : Docker (durci non-root), Render / Google Cloud Platform (Cloud Run, Cloud SQL)
• Mobile & Web : Flutter (Dart), HTML5 / Tailwind / Chart.js
• Agent EDR : PowerShell natif Windows

🔗 Tester la démo en direct : https://sentinel-watch-ssty.onrender.com/dashboard
```

```text
🚀 De l'idée à la production : pourquoi j'ai codé mon propre système de détection d'intrusions (SIEM / EDR).

Quand on étudie la cybersécurité, analyser des logs statiques est formateur. Mais concevoir l'architecture complète d'un système capable de réagir en direct face à une attaque, c'est un tout autre niveau d'apprentissage.

C'est ainsi qu'est né SentinelWatch 🛡️ :
• Détecter un "voyage impossible" quand un compte se connecte à Paris puis à Tokyo en quelques secondes (calcul de vélocité Haversine).
• Repérer les attaques par force brute et les sondes de hackers (fuzzing d'endpoints sensibles).
• Piloter les alertes depuis un smartphone et neutraliser les attaquants au pare-feu en un seul tap.

Ce projet m'a permis de lier mes compétences en développement backend (FastAPI), conteneurisation Docker, Machine Learning (Isolation Forest) et mobilité (Flutter).
```
